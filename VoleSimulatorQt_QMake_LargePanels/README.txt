VOLE Simulator - Qt Widgets (QMake)

How to open:
1. Extract the ZIP file.
2. Open Qt Creator.
3. Choose File > Open File or Project.
4. Select VoleSimulatorQt.pro.
5. Select a Qt 6 kit with Desktop compiler support.
6. Click Configure Project.
7. Build, then Run.

The project uses QMake (.pro), not CMake.
The example program(1).txt through program(10).txt files are included.
